# Recorded percussion

These 28 acoustic one-shots are selected from the
[Versilian Community Sample Library](https://github.com/sgossner/VCSL), an
explicitly [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
sample collection. Browser-ready source encodes came from the
[`smpldsnds/sgossner-vcsl`](https://github.com/smpldsnds/sgossner-vcsl)
mirror at commit `62296c0b7916f273b623513c74b140aa7b9696ee` and were converted
locally from M4A to mono 96 kbps MP3.

The compact selection contains round-robin recordings of acoustic bass drum,
modern snare, sidestick, hi-hat, cajon, conga, bongos, shaker, claves,
tambourine and woodblock. 21FM alternates the paired recordings so a
repeated rhythm does not replay the exact same waveform on every hit.
