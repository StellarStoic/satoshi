Patterns on the Pinstr board
=============================

These are the patterns a reader can choose for their board. Every one is a "Subtle
Pattern" from Toptal, https://www.toptal.com/designers/subtlepatterns/, used under
Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0,
https://creativecommons.org/licenses/by-sa/3.0/). That is the licence the collection's
own repository states, https://github.com/atlemo/SubtlePatterns.

Attribution is required: the designer's name travels with the pattern, and a pattern that is
modified or built on stays under this same licence. Using a pattern unchanged as a background does
not put the board's own code under it - but keep this file with the images, and keep the credit
where a reader can find it.

Two notes for whoever touches these next:
  - dot-grid is a JPEG that the source serves under a .png name, so it is kept here as
    a .jpg and named as one.
  - carbon fibre is a 24x22 tile. At the board's usual 600px tile it would repeat
    twenty-five times inside one cork tile, so its catalogue entry names a 96px tile.
