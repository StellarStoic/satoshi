# Archived BIP39 playground

These source files preserve the interactive phrase, entropy, checksum and
passphrase playground that preceded the simplified BIP39 word checker.
They use `.source` extensions so the archived page is not published as a
second live interface.

To restore it later, copy the three files to the project root using their
original `.html`, `.css` and `.js` extensions. The supporting
`bip39Lab.mjs`, `bip39LabModel.mjs`, `bip39Lab.css` and
`bip39Glossary.mjs` files remain in the project root.
