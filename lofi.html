    Under the headphones

    How Bitcoin becomes a listening session

    This is not a playlist with blockchain decoration. The browser turns live public Bitcoin data into musical decisions, then keeps those decisions inside Lo-Fi boundaries so the result remains listenable.

    1. 01

      A block builds the studio

      The block hash is a unique seed. Its bytes choose the key, scale, chord progression, tempo, swing, arrangement, synth voices, drum kit, room, motion and tape character. A different block creates a different studio.

      hash → musical world
    2. 02

      The mempool conducts it

      Waiting transaction count, projected blocks and fee pressure continuously shade tempo, brightness, percussion density, echo and noise. Busy does not simply mean loud; it means more energy and detail.

      pressure → energy
    3. 03

      Transactions write phrases

      Incoming TXIDs reshape the next phrase. Sampled transaction size controls note length and visual mass; fee rate affects brightness and speed; inputs, outputs, RBF and script family influence rhythm, voicing and color.

      transactions → variation
    4. 04

      A new block dissolves in

      The current session first recedes into a filtered wash. The new block changes the ensemble at the quiet point, then rises over two bars. The chain advances without an abrupt track cut.

      old block ⇢ new block
