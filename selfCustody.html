    A signing device protects the key that authorizes a payment. A node checks that the payment follows Bitcoin's rules. They solve different problems, and they work well together.

    01

    The wallet does not contain bitcoin

    Your bitcoin is recorded on Bitcoin's public ledger. A hardware wallet or signing device holds a private signing key. That key creates the proof needed to move your bitcoin to another address.

    Think of the device as a pen that can produce a signature nobody else can copy. The wallet app prepares the form; the device lets you inspect and sign it.

    If the device breaks, your bitcoin is not trapped inside it. A correct recovery backup can rebuild the same keys on a compatible device. Anyone who finds that backup can do the same, so keep it offline and private.

    Choose how hands-on you want to be

    Choose a wallet app

    A wallet app shows balances, creates transactions and broadcasts them. A phone or computer connected to the internet is convenient, but treat it as spending money unless an offline signing device protects the key.

    Protect your signing key

    DIY · air-gapped · stateless

    SeedSigner

    Build it from commonly available parts. A Raspberry Pi Zero 1.3 without Wi-Fi or Bluetooth exchanges transaction data through QR codes. It is intentionally more hands-on and does not persist your seed by default.

    Good forPeople who want transparent parts, QR signing and a project they can assemble themselves.
    Official project

    Reuse an old phone · offline QR signer

    Cupcake

    Turn a wiped Android phone with no network connection into a QR signing companion for Cake Wallet. It is an accessible way to learn offline signing, but a general-purpose phone is not a dedicated security device.

    Good forLearning and modest balances. Use a dedicated signer or carefully designed multisig for serious savings.
    Cupcake guide

    Ready-made · Bitcoin-only option

    BitBox02 Bitcoin-only edition

    The Bitcoin-only BitBox02 is designed for a smoother first setup. Its open-source firmware uses reproducible builds, while a separate secure chip hardens access to the signing key.

    Good forPeople who prefer a compact finished product with guided software and straightforward backups.

    Verify Bitcoin with your own node

    A node downloads and checks Bitcoin's history and new transactions. Connecting your wallet to it means you ask your own computer about balances and payments instead of trusting somebody else's server.

    Plug-and-play or DIY · personal server

    Start9

    StartOS provides a graphical personal server for Bitcoin Core, Lightning and other self-hosted services. Buy supported hardware or install the open-source system yourself.

    Start9 docs

    RaspiBlitz

    An MIT-licensed project with ready-to-flash images for Raspberry Pi hardware. It combines a full Bitcoin node, optional Lightning and a dashboard without hiding the machinery.

    A detailed build-it-yourself guide rather than an appliance. You install and configure the node layer by layer, which takes longer but teaches you what each component does.

    Bitcoin Core

    The reference implementation validates the complete Bitcoin chain and includes its own wallet. It needs substantial storage, bandwidth and synchronization time; many users run Core as their node and use Sparrow as the interface.

    03

    Before moving meaningful bitcoin

    1. Use official sources. Verify downloads and never buy a device that arrives already initialized.
    2. Keep recovery words offline. Never type them into this website, a chat, cloud storage or a general-purpose computer.
    3. Verify on the device. Check the destination address and amount on the signer's own screen.
    4. Practice recovery. Learn with a small amount and test the backup before depending on it.
    5. Remember the boundary. A node verifies rules; it does not replace secure key storage.
