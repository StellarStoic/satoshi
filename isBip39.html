02 / UNDER THE HOOD

Bits first. Words second.

A wallet starts with random bits, called entropy. It adds a short checksum, then splits the result into 11-bit pieces and looks up a word for each piece.

A bit can be 0 or 1. Flipping one changes the example; its checksum is recalculated too. A real wallet generates these bits randomly, instead of choosing memorable words.

A checksum is a small error check made from SHA-256. Passing it does not mean a phrase is secret or safe. Recalculating it here changes the example; it does not recover a lost wallet.

03 / THE OPTIONAL EXTRA

Same words. Different seed.

The words and an optional passphrase are combined to produce a 64-byte seed. Wallet software uses that seed to derive keys and addresses.

Sometimes called the "13th" or "25th word", a passphrase can be a whole sentence. It is separate from the word list. Leaving it empty is valid.

Each pair below is one byte, written in hexadecimal.

Without a passphrase

With your practice passphrase

Case and spaces matter. A different passphrase leads to a different wallet, with no "wrong passphrase" error. You need the exact phrase and passphrase to return to the same wallet.

The technical recipe

BIP39 uses PBKDF2-HMAC-SHA512 with 2,048 iterations. The mnemonic is the password, and "mnemonic" plus the passphrase is the salt. Both use Unicode NFKD normalization. The output is always 512 bits (64 bytes), not a Bitcoin address.

What is this tool?

This tool helps you check if a word is part of the official BIP39 English word list used in Bitcoin wallets for generating seed phrases (mnemonics).

We currently only support the English version of the BIP39 word list, which contains exactly 2048 unique words standardized for secure phrase generation.

As you type, the input will validate whether the word is part of the list, and show suggestions that match what you're typing.

If the word isn't valid, we suggest similar English words using the Datamuse API — an open API for finding related words based on spelling and pronunciation.
